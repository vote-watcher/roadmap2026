# Smoke-тесты дорожной карты голосования

Установка зависимостей и браузеров:

```sh
npm install
npx playwright install chromium firefox webkit
```

Запуск кроссбраузерных smoke-тестов:

```sh
npm run test:smoke
```

Тесты открывают обе локальные HTML-страницы в Chromium, Firefox, desktop WebKit
и WebKit с профилем iPhone. Последний является приближением Safari: настоящий
iOS Safari требует отдельного реального устройства и в этот набор не входит.

Код страницы рассчитан на Safari 13.1 и новее. Это подтверждено отсутствием
парсерно несовместимых `||=`, regex lookbehind и `.at(-1)`; `matchAll` также не
используется. iOS 12 этим набором не обещается.

Тесты проверяют отсутствие console/page errors, публичную модель и строгий
инвариант покрытия, контрольные счетчики и разбиение расписания, все 39
карточек picker, видимость основных элементов, скрытие всех прямых служебных
детей `body`, поиск, очистку поиска и выбор карточки. Видео, скриншоты и trace
отключены, тестовые артефакты в репозиторий не сохраняются.
